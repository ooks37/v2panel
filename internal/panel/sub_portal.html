② 下载并安装客户端

按你的设备选一个。只需要装一个，不用全装。
Clash Verge Rev Windows / macOS / Linux
  1. 下载并安装（Windows 选 .exe）
  2. 打开后点左侧 订阅 → 顶部 新建
  3. 把复制的地址粘进 订阅链接，名字随便填，点 导入
  4. 回 代理 页，选一个节点，打开右上角开关
官网：github.com/clash-verge-rev
v2rayN Windows
  1. 下载 v2rayN-windows-64.zip，解压后运行 v2rayN.exe
  2. 顶部 订阅分组 → 订阅分组设置 → 添加
  3. 地址栏粘贴订阅链接，备注随便填，确定
  4. 回主界面按 Ctrl+R 更新订阅，双击节点即可
下载：github.com/2dust/v2rayN
v2rayNG Android
  1. 在 Releases 里下载 .apk 安装
  2. 左上角 ☰ → 订阅分组 → +
  3. 粘贴订阅链接，右上角 ✓ 保存
  4. 回主界面点右上角 ⋮ → 更新订阅，再点节点连接
下载：github.com/2dust/v2rayNG
Shadowrocket iOS / iPadOS
  1. 在 App Store 搜索 Shadowrocket（付费，约 ¥18）
  2. 打开后右上角 + → 类型选 Subscribe
  3. URL 栏粘贴订阅链接，保存
  4. 左滑这条订阅 → 更新，再点节点打开顶部开关
